    연습문제 5개 바로가기

    표시 없는 본문은 원본 정리 파일의 내용 · 보충은 원본에 없어 더한 설명 · 가상 예시는 지어낸 상황 · 연결은 다른 단원과의 관계 · 확인 필요는 그대로 확정하지 않은 부분

    물리 보안은 D3.8 사이트·설비 설계 원칙·D3.9 사이트·설비 보안 통제에서 “설계” 관점으로 다뤘습니다. 이 단원은 공식 개요 7.14의 표현대로 물리 보안을 구현하고 관리하는 운영 관점입니다. 원본은 출발점을 다시 확인합니다. 물리적 접근이 뚫리면 논리적 통제 상당수가 무력화된다. 그리고 설계와 운영 전체를 관통하는 등식 하나를 제시합니다. 지연 시간 > 탐지 + 평가 + 대응 시간.

    1물리 보안의 다섯 목표

    물리적 접근이 가능하면 디스크 분리, 콘솔 접근, 하드웨어 임플란트, 네트워크 포트 접속, 매체 절취가 모두 가능해집니다. 그래서 원본은 물리 보안이 논리 보안의 전제라고 말합니다.

    억제 Deter
    →
    지연 Delay
    →
    탐지 Detect
    →
    평가 Assess
    →
    대응 Respond
    목표의미예
    억제시도 자체를 포기하게울타리, 조명, 표지, 가시적 카메라
    지연침입에 시간이 걸리게 해 대응 인력이 올 시간을 벎장벽, 잠금, 구역 분리
    탐지침입을 인지센서, 카메라, 경보
    평가실제 침입인지 오경보인지 판단. 평가 없는 탐지는 대응으로 이어지지 않음카메라 연동, 경비 확인
    대응인력 개입경비, 경찰

    기본 등식: 지연 시간 > 탐지 + 평가 + 대응 시간이어야 침입이 성공하지 못합니다. 그리고 인원 안전이 모든 물리 보안 설계에 우선합니다. 비상구는 안에서 항상 열려야 하며, 이것이 보안과 안전이 충돌할 때 안전이 이기는 대표적 예입니다.

    원문 사례 — 평가가 없어 대응되지 않은 탐지. 경계 센서 경보에 카메라 연동과 판단 절차가 없었고, 야간 오경보가 잦아 경비가 경보를 무시하게 되어 실제 침입 때도 확인 없이 종결했습니다. 센서 경보에 해당 구역 카메라를 자동 연동하고, 오경보 원인(조경, 동물, 기상)을 제거하고, 경보 처리 기록을 의무화했습니다.

    보충통제 하나가 여러 기능을 할 수 있습니다. 울타리는 억제하고 지연시키며, 카메라는 억제하고 탐지하며(누군가 보고 있을 때), 자물쇠는 지연시킵니다. 그래서 “이 통제가 어떤 기능인가”보다 “다섯 기능이 모두 어딘가에서 채워지는가, 특히 평가가 빠지지 않았는가”를 보는 편이 설계 점검에 유용합니다.

    연결물리 보안의 네 가지 기능과 인명 안전은 D3.8 사이트·설비 설계 원칙의 1절과 7절에서 다뤘습니다.

    원본 연습문제 · D7.14-Q11

    울타리, 보안 카메라, 출입문 자물쇠는 각각 주로 어떤 기능을 하는가?

    1. 카메라가 예방하고 자물쇠가 탐지한다.
    2. 셋 다 탐지 통제다.
    3. 울타리는 억제하고 지연시키며, 카메라는 억제하고 탐지하며, 자물쇠는 예방한다. 따라서 물리 보안은 하나를 반복하는 것이 아니라 기능을 조합해 구성한다.
    4. 셋 다 예방 통제다.
    정답과 해설 보기

    정답 C. 통제는 억제·예방·탐지·교정 같은 기능으로 분류된다. 카메라는 침입을 물리적으로 막지 못하지만 보인다는 사실로 억제하고 사후 확인을 가능하게 한다. 자물쇠는 막지만 누가 시도했는지 알려 주지 않는다. 그래서 억제와 예방, 탐지, 대응을 함께 갖춰야 공백이 없다.

    • A · 기능이 뒤바뀐 설명이다.
    • B · 자물쇠는 탐지하지 않는다.
    • D · 카메라는 예방하지 않는다.

    2CPTED와 심층 방어

    CPTED 원칙내용
    자연적 감시보이는 공간, 사각지대 제거, 조명, 시야
    자연적 접근 통제동선을 설계로 유도(하나의 주 출입구, 조경)
    영역성공적·사적 공간의 경계 명확화
    유지 관리방치된 공간은 범죄를 끌어들임(깨진 창 이론)

    원본은 CPTED의 가치를 사람이 “여기 있으면 눈에 띈다”고 느끼게 만드는 것이 카메라 한 대보다 효과적인 경우가 많다는 데서 찾습니다.

    심층 방어의 물리적 적용: 외부 경계(울타리, 차량 장애물) → 부지(조명, 감시) → 건물 외벽(출입구, 창문) → 내부 구역(접수, 일반, 제한) → 고보안 구역(데이터센터, 금고) → 랙과 캐비닛. 각 계층이 억제·지연·탐지를 제공하고 안쪽으로 갈수록 통제가 강해집니다.

    연결CPTED와 계층적 방어의 설계는 D3.8 사이트·설비 설계 원칙의 2절과 3절에서 자세히 다뤘습니다.

    원문 위치: D7.14.md §3 CPTED, 심층 방어의 물리적 적용

    3경계 통제 (Perimeter Security Controls)

    통제운영 요점
    울타리와 장벽높이에 따라 경계 표시~결연한 침입자 지연. 상단·지면 처리. 벽은 지연 효과가 크지만 내부 가시성을 차단해 자연적 감시를 약화
    차량 장애물볼라드·차단기, 크래시 레이팅, 우회 경로 차단, 구불구불한 접근로
    조명억제와 탐지, 카메라의 전제. 균일성이 밝기보다 중요(극단적 명암 대비는 그림자 은폐를 쉽게 함), 눈부심 방지, 비상 전원
    출입구수 최소화, 출입구 강도가 울타리보다 약하면 그것이 약한 고리, 경첩 방향, 강화·접합 유리, 정전 시 동작 결정

    Fail-safe와 Fail-secure

    구분정전 시 동작우선적용
    Fail-safe잠금 해제(열림)인원 안전사람이 갇힐 수 있는 문
    Fail-secure잠금 유지(닫힘)자산 보안무인 자산 보관 구역

    원문 사례 — Fail-secure로 설정된 비상구. 보안 강화를 위해 모든 전자 잠금을 fail-secure로 설정했다가, 정전 훈련에서 일부 구역에서 사람이 나올 수 없는 상황이 발견되었습니다.

    원문 사례 — 조명의 극단적 대비. 주차장 고출력 조명의 간격이 넓어 밝은 구역과 매우 어두운 구역이 번갈아 나타났고, 침입자가 어두운 구간에 머물며 접근할 수 있었으며 카메라도 명암 차이로 식별이 어려웠습니다.

    원문 사례 — 벽은 튼튼했으나 창문으로 들어간 침입. 데이터센터 구역의 벽과 출입문을 보강했지만, 침입자는 인접 사무실의 일반 유리창을 깨고 들어와 내부에서 접근했습니다. 원본은 가장 약한 고리가 전체 수준을 결정한다고 정리합니다. 창문, 환기구, 천장 공간, 상승 바닥 아래까지 모든 개구부를 점검했습니다.

    주의물리 보안의 fail-safe(사람 안전 → 열림)와 정보 보안의 fail-safe/fail-secure(데이터 보호 → 차단)는 같은 단어가 다른 방향을 가리킬 수 있습니다. 문맥에서 “무엇을 보호하는가”를 먼저 확인합니다(D3.1 안전한 설계 원칙).

    원본 연습문제 · D7.14-Q01

    보안 강화를 위해 시설 전체의 전자 잠금이 fail-secure 로 설정되었다. 정전 훈련에서 일부 구역에서 직원이 나올 수 없음이 발견되었다. 잠금을 어떻게 구성해야 하는가?

    1. 정전 시에도 내부에서 안전하게 탈출할 수 있게 하고 외부 진입 잠금은 적용 기준과 구역의 요구에 맞게 설계한다.
    2. 전원에 의존하지 않는 기계식 잠금으로 모든 전자 잠금을 교체한다.
    3. 모든 잠금을 fail-secure 로 유지하고 정전 중 각 문에 경비를 배치한다.
    4. 어떤 구역도 접근 불가가 되지 않도록 모든 잠금을 fail-safe 로 구성한다.
    정답과 해설 보기

    정답 A. 내부 퇴실 보장과 외부 진입 잠금의 전원 상실 동작을 따로 설계합니다. 예를 들어 미국 OSHA의 일반 출구 규칙은 내부에서 열쇠나 특별한 지식 없이 문을 열 수 있어야 한다고 정하며, 외부 진입만 막는 방식도 허용합니다. 실제 설비는 적용되는 시설 안전 기준과 승인 조건을 확인합니다. OSHA 1910.36(d)

    • B · 기계식 전환은 출입 기록과 중앙 통제를 포기하는 것이다.
    • C · 경비 배치는 비용이 과도하고 즉시성이 보장되지 않는다.
    • D · 전부 fail-safe 는 정전 시 자산 구역이 개방된다.

    4감시 (Surveillance)

    • 카메라 설계: 커버리지, 해상도, 야간 성능, 저장 기간. 해상도가 낮으면 식별할 수 없고 증거 가치가 없습니다.
    • 탐지·인식·식별(움직임이 있다 / 아는 사람인가 / 누구인가)에 필요한 해상도가 다릅니다.
    • 녹화 보존: 짧으면 사후 조사가 불가능합니다.
    • 아무도 보지 않는 카메라는 탐지 통제가 아니라 사후 증거 수집 수단입니다.
    • 경비 인력: 판단과 대응이 가능한 유일한 통제. 비용이 높고 일관성 관리가 필요합니다.
    • 침입 탐지 센서(동작, 적외선, 유리 파손, 진동, 자기 접촉): 오경보 관리가 운영의 핵심.
    • 프라이버시: 감시 범위·고지·보존 기간에 법적 요건, 탈의실·휴게 공간 등은 제한.

    원문 사례 — 해상도가 부족한 카메라. 침입 후 영상을 확인했지만 해상도가 낮아 사람이 지나갔다는 사실만 확인되었습니다. 목적별 요구 해상도를 정의하고, 출입구와 중요 구역에는 식별 가능 수준의 카메라를 두고, 녹화 보존 기간을 조사 요구에 맞췄습니다.

    연결증거 보존과 조사는 D7.1 조사, 근로자 모니터링의 법적 요건은 D1.4 법률·규제·컴플라이언스에서 다룹니다.

    원문 위치: D7.14.md §3 감시, §7 사례 3

    5내부 통제 (Internal Security Controls)

    구역 분리와 출입 통제

    공개 구역(로비) → 일반 업무 → 제한 → 고보안(데이터센터)으로 등급화하고, 알 필요성과 최소권한을 물리 공간에 적용합니다. 등급이 올라갈 때마다 인증을 요구하고, 방문자가 제한 구역을 지나지 않게 동선을 설계합니다.

    수단요점
    배지와 카드비접촉 카드, 스마트카드. 저가 근접 카드는 복제가 쉬움
    PIN 결합카드(소유) + PIN(지식)의 다중 인증
    생체 인증고보안 구역. FRR/FAR 트레이드오프
    출입 기록입실과 퇴실 모두 기록해야 재실 인원 파악과 상관분석 가능
    반출입 통제매체와 장비의 반출입 승인과 기록

    테일게이팅

    가장 흔한 물리 침입 수법입니다. 대응은 맨트랩(access control vestibule — 두 문 사이 공간, 한 번에 한 사람), 회전문, 반통과 감지(anti-passback, 같은 카드 연속 입실 차단), 인원 수 감지, 경비 배치, 그리고 문화와 교육입니다.

    원본은 테일게이팅이 예의와 보안이 충돌하는 지점이라고 말합니다. 문을 잡아 주지 않는 것이 무례해 보여 사람들이 통제를 우회하므로, 교육의 핵심은 “제지는 무례가 아니다”와 “제지한 사람을 조직이 지지한다”는 메시지입니다.

    원문 사례 — 테일게이팅 침투 테스트. 승인된 물리 침투 테스트에서 테스터가 커피 두 잔을 들고 출입구에서 기다리자 직원이 문을 잡아 주었고 제한 구역까지 들어갔으며, 이후 수리 기사로 위장해 서버실에도 들어갔습니다. 회전문·맨트랩·반통과 감지와 함께 위 메시지 중심의 교육을 했고, 원본은 기술만으로는 해결되지 않았다고 정리합니다.

    기타 사회공학과 내부 설비

    위장(수리 기사, 배송, 청소, 감사인 사칭), 분실물 반환 구실, 흡연 구역 출입문·배송 구역처럼 통제가 약한 보조 출입구, 문서·매체 절취. 대응은 방문자 등록과 에스코트, 공급자 사전 등록, 배지 착용 의무, 보조 출입구 통제입니다.

    내부 설비: 잠금 랙과 캐비닛(코로케이션에서는 필수), 미사용 네트워크 포트 비활성화와 포트 보안(회의실 포트가 흔한 침입 경로), 접근 가능한 배선 보호, 매체 잠금 보관, 깨끗한 책상과 화면 잠금(가장 저비용의 통제).

    원문 사례 — 회의실 네트워크 포트. 방문자가 쓰는 회의실에 활성 사내 네트워크 포트가 있어, 침투 테스터가 소형 기기를 연결해 원격 접근 경로를 확보했습니다. 미사용 포트 비활성화, 포트 보안과 802.1X, 방문자 구역의 별도 세그먼트 분리로 대응했습니다.

    가상 예시청소 협력사가 야간에 병원 행정동을 이용하는데, 건물 출입 카드로 서버실과 의무기록 보관실까지 열린다고 합시다. 건물 출입은 “방문 이유와 시간”을 확인하는 외곽 경계이고, 서버실과 기록실은 “별도로 보호할 자산”의 내부 경계입니다. 두 경계의 권한을 하나로 묶으면 외곽에서 확인한 사람이 내부 자산까지 접근하게 됩니다. 야간 청소가 필요한 내부 구역은 동행이나 시간 제한 권한으로 따로 줍니다.

    연결포트 보안과 NAC는 D4.2 네트워크 구성요소의 5절, 802.1X는 D5.6 인증 시스템의 6절, 사회공학은 D1.12 인식·교육·훈련, 매체 보관은 D7.5 자원 보호에서 다룹니다.

    원본 연습문제 · D7.14-Q04

    승인된 물리 침투 테스트에서 커피 두 잔을 든 테스터가 출입구에서 대기했고 직원이 문을 잡아주어 제한 구역 접근이 허용되었다. 이를 가장 효과적으로 해소하는 조합은?

    1. 직원이 서로를 알아볼 수 있도록 사진이 있는 배지 발급.
    2. 제한 구역 출입이 허용된 직원 수 축소.
    3. 다른 사람을 위해 문을 잡아주는 것을 금지하는 표지 게시.
    4. 반통과 감지를 갖춘 회전문이나 맨트랩과 함께 제지는 무례가 아니며 제지한 사람을 조직이 지지한다는 메시지의 교육.
    정답과 해설 보기

    정답 D. 테일게이팅은 가장 흔한 물리 침입 수법이며 예의와 보안이 충돌하는 지점이라 기술만으로 해결되지 않는다. 회전문과 맨트랩은 물리적으로 한 명씩 통과시키고 반통과 감지는 카드 전달을 막는다. 동시에 제지가 무례가 아니라는 메시지와 제지한 사람에 대한 조직의 지지가 필요하다.

    • A · 사진 배지는 대규모 조직에서 식별 효과가 제한적이다.
    • B · 출입 인원 축소는 업무를 제약하며 테일게이팅 자체를 막지 않는다.
    • C · 표지만으로는 행동이 바뀌지 않는다.

    원본 연습문제 · D7.14-Q08

    침투 테스트에서 테스터가 방문자 회의실의 활성 상태 사내 네트워크 포트에 소형 기기를 연결해 원격 접근을 확보했다. 이를 해소하는 통제는?

    1. 기기를 숨길 수 없도록 회의실에서 모든 가구를 제거한다.
    2. 미사용 포트를 비활성화하고 포트 보안과 802.1X 를 적용하며 방문자 구역을 별도 네트워크 세그먼트에 배치한다.
    3. 방문자가 접수처에서 모든 전자 기기를 반납하도록 요구한다.
    4. 모든 방문 중 회의실을 카메라로 감시한다.
    정답과 해설 보기

    정답 B. 방문자가 접근할 수 있는 공간의 활성 네트워크 포트가 흔한 침입 경로다. 미사용 포트를 비활성화하고 포트 보안과 802.1X 로 인증 없는 연결을 차단하며 방문자 구역을 별도 세그먼트로 분리해야 한다. 물리 통제와 네트워크 통제의 결합이 필요하다.

    • A · 가구 제거는 비현실적이고 포트 자체를 막지 않는다.
    • C · 기기 반납은 업무를 저해하고 실효성이 낮다.
    • D · 카메라는 사후 증거이며 연결을 차단하지 않는다.

    6환경 통제의 운영

    전원, 공조, 화재, 수해의 원리와 종류는 D3.9 사이트·설비 보안 통제에서 다뤘습니다. 여기서는 원본이 강조하는 운영상의 함정에 집중합니다.

    영역운영 요점
    UPS단기 정전과 발전기 전환까지의 가교. 배터리 수명 관리와 주기 부하 시험
    발전기연료 공급 계약과 주기 부하 시험. 연료가 없으면 발전기는 장식
    전원 품질서지, 스파이크, 새그, 브라운아웃, 블랙아웃. 이중 전원, 접지, 서지 보호
    공조온습도(과열·정전기·부식), 핫/콜드 아일 분리, 양압. 경보가 처리되지 않으면 센서는 무용
    화재조기 감지가 핵심(초기 → 연기 → 화염 → 열, 열 감지가 가장 늦음). 데이터센터에는 사전 작동식 스프링클러, 가스 소화는 방출 전 경보·대피·밀폐 유지. 전기 화재에 물 금지
    수해데이터센터를 지하·최상층에 두지 않음, 배관 경로, 누수 감지(상승 바닥 아래)

    원문 사례 — 연료 없는 발전기. 광역 정전에서 UPS는 정상 작동해 발전기로 넘어갔지만, 연료가 8시간분뿐이고 공급 계약이 없었는데 정전은 32시간 이어졌습니다. 연료 공급 우선 계약, 보유 연료 기준 가동 가능 시간 지표, 주기 부하 시험으로 대응했습니다.

    원문 사례 — 시험되지 않은 UPS 배터리. UPS가 정상으로 표시되었지만 실제 정전에서 배터리가 90초 만에 소진되어 발전기 전환 전에 시스템이 다운되었습니다. 배터리가 수명을 넘겼는데 부하 시험을 하지 않았습니다.

    원문 사례 — 습식 스프링클러 오작동. 데이터센터의 습식 스프링클러 배관이 손상되어 화재 없이 방수가 일어나 장비가 침수되었습니다. 사전 작동식으로 교체하고 누수 감지를 보강했습니다.

    연결화재 등급·소화 약제·스프링클러 4종은 D3.9 사이트·설비 보안 통제의 9~12절, 전력 이상과 이중화는 D3.9 사이트·설비 보안 통제의 13~14절, TEMPEST는 D4.2 네트워크 구성요소에서 다룹니다.

    원문 위치: D7.14.md §3 환경 통제, §7 사례 8~10

    7운영과 관리

    • 출입 권한 검토: 논리 접근과 같이 주기 검토. 퇴사자 출입증 회수는 자주 누락됩니다.
    • 방문자 관리: 등록, 신원 확인, 배지 발급, 에스코트, 반납 확인.
    • 공급자·유지보수 인력: 사전 등록, 작업 승인, 동행, 작업 기록.
    • 설비 유지보수: UPS 배터리, 발전기 부하 시험, 소화 설비 점검, 센서 교정. 시험되지 않은 비상 설비는 작동하지 않습니다.
    • 물리·논리 로그 상관분석: 출입 기록과 인증 로그 교차 확인으로 자격증명 도용 탐지.
    • 물리 침투 테스트: 테일게이팅, 위장, 보조 출입구를 실제로 시험. 서면 승인과 비상 연락처 필수.

    원문 사례 — 퇴사자 출입증 회수 누락. 접근 검토에서 퇴사자 출입증 34건이 활성 상태였습니다. 논리 계정은 차단되었지만 물리 출입 권한은 별도 시스템이라 퇴사 절차에 없었습니다. 출입 통제 시스템을 인사 이벤트에 연동하고 출입 권한 검토를 정기 접근 검토에 넣었습니다.

    보충출입 기록을 쌓는 것과 부정 출입을 알아내는 것은 다른 작업입니다. 미반납 카드, 비정상 시간 사용, 승인과 다른 출입을 검토하는 조건과 처리 담당자를 정해 두어야 기록이 통제가 됩니다. 로그를 “수집만” 하면 탐지가 아니라는 D7.2 로깅·모니터링의 원칙이 물리 출입 기록에도 그대로 적용됩니다.

    연결계정 생애주기와 접근 검토는 D5.5 프로비저닝 생애주기, 물리·논리 상관분석 사례는 D5.1 물리적·논리적 접근 통제의 3절, 테스트의 서면 승인은 D6.1 평가·테스트·감사 전략의 6절에서 다룹니다.

    원문 위치: D7.14.md §3 운영과 관리, §7 사례 11

    8종합 이해 확인

    종합 · 자작 상황 문제 (실제 시험 문제 아님)

    물리 보안 점검 결과다. ㉠ 경계 센서 경보가 잦아 경비가 확인 없이 종결한다. ㉡ 모든 전자 잠금이 fail-secure다. ㉢ 직원들이 낯선 사람에게도 문을 잡아 준다. ㉣ 퇴사자 출입증 34건이 활성 상태다. 가장 적절한 대책 묶음은?

    1. ㉠ 센서 감도를 낮춤 / ㉡ 그대로 유지 / ㉢ 문에 경고문 부착 / ㉣ 다음 연례 점검 때 정리
    2. ㉠ 카메라 자동 연동·오경보 원인 제거·처리 기록(평가 단계 보강) / ㉡ 사람이 갇힐 수 있는 문은 fail-safe, 무인 자산 구역은 fail-secure / ㉢ 맨트랩·반통과 감지와 “제지는 무례가 아니다” 교육·지지 문화 / ㉣ 출입 통제를 인사 이벤트에 연동, 정기 접근 검토에 포함
    3. ㉠ 센서 철거 / ㉡ 모두 fail-safe로 / ㉢ 문을 잡아 준 직원 징계 / ㉣ 출입증 재발급
    4. ㉠ 경비 증원만 / ㉡ 비상구 잠금 강화 / ㉢ 카메라 추가만 / ㉣ 논리 계정만 확인
    정답과 해설 보기

    정답 B. ㉠ 1절(평가 없는 탐지는 대응으로 이어지지 않음), ㉡ 3절(사람 안전이 우선, 단 무인 자산은 fail-secure — C의 “모두 fail-safe”도 틀림), ㉢ 5절(기술과 문화 함께, 징계는 역효과), ㉣ 7절(물리 출입도 생애주기 관리).

    복습

    첫 출입문에서 등록한 방문자에게 내부 구역까지 허용해도 될까요?

    설명 확인하기

    승인된 방문 목적과 시간은 특정 범위를 정합니다. 내부 제한 구역은 별도 권한과 필요한 동행을 적용합니다. 방문을 끝내면 카드 회수와 비활성화를 확인합니다.

    10핵심 요약

    1. 물리 보안은 논리 보안의 전제. 다섯 목표: 억제 → 지연 → 탐지 → 평가 → 대응. 평가 없는 탐지는 대응으로 이어지지 않는다.
    2. 설계 등식: 지연 시간 > 탐지 + 평가 + 대응 시간. 인원 안전이 모든 설계에 우선.
    3. CPTED(자연적 감시, 접근 통제, 영역성, 유지 관리)와 계층적 방어(경계 → 부지 → 외벽 → 내부 → 고보안 → 랙).
    4. 경계: 울타리(벽은 가시성 차단), 차량 장애물(우회 차단), 조명은 균일성, 출입구가 약한 고리가 되지 않게. 가장 약한 고리가 전체 수준.
    5. Fail-safe = 열림(사람 안전), Fail-secure = 닫힘(자산 보안). 사람이 갇힐 수 있는 문은 fail-safe.
    6. 감시: 탐지·인식·식별 해상도, 보존 기간, 아무도 안 보는 카메라는 사후 증거 수단, 경비는 유일한 판단·대응 통제, 오경보 관리.
    7. 내부: 구역 등급, 카드+PIN, 입퇴실 모두 기록. 테일게이팅 → 맨트랩·회전문·반통과 + 문화(제지는 무례가 아니다). 회의실 포트, 깨끗한 책상.
    8. 환경 운영: UPS 배터리 부하 시험, 발전기 연료 계약, 경보 처리, 데이터센터는 사전 작동식, 지하·최상층 회피.
    9. 운영: 출입 권한 검토(퇴사자 출입증), 방문자·공급자 관리, 비상 설비 시험, 물리·논리 상관분석, 승인된 물리 침투 테스트.
    원문 위치: D7.14.md §8 CISSP 시험 관점, §9 핵심 암기 요약. 원본의 출제 단정 표현은 판단 기준으로 바꿔 적었습니다.

    11주요 용어 (Glossary)

    영어 원어와 한국어 뜻 · English–Korean

    Deter / Delay / Detect / Assess / Respond · 억제 / 지연 / 탐지 / 평가 / 대응

    물리 보안의 목표 순서. 억제, 지연, 탐지, 평가, 대응.

    CPTED (Crime Prevention Through Environmental Design) · 환경 설계를 통한 범죄 예방

    환경 설계로 범죄를 예방하는 접근. 자연적 감시, 접근 통제, 영역성, 유지 관리.

    Bollard · 볼라드

    차량 돌진을 막는 고정 장애물.

    Crash Rating · 크래시 레이팅

    차량 중량과 속도에 대한 장애물의 저항 등급.

    Fail-safe / Fail-secure · 고장 시 안전 상태 / 고장 시 보안 상태 유지

    정전 시 잠금이 해제되는 방식과 유지되는 방식. 안전 우선과 보안 우선.

    Mantrap / Access Control Vestibule · 맨트랩

    두 문 사이 공간으로 한 번에 한 사람만 통과시키는 구조.

    Anti-passback · 반통과 감지

    같은 카드의 연속 입실을 차단해 카드 전달을 막는 기능.

    Tailgating / Piggybacking · 테일게이팅

    인증된 사람 뒤를 따라 들어가는 침입 수법.

    Pretexting · 위장

    수리 기사나 배송 등으로 신분을 사칭하는 사회공학.

    Hot Aisle / Cold Aisle · 핫 아일 / 콜드 아일

    데이터센터의 더운 공기와 찬 공기 통로 분리 설계.

    Positive Pressure · 양압

    내부 기압을 외부보다 높게 유지해 오염 유입을 막는 방식.

    Sag / Brownout / Blackout · 순간 전압 강하 / 지속 저전압 / 정전

    단기 전압 저하, 장기 저전압, 완전 전원 차단.

    Wet / Dry / Pre-action / Deluge Pipe · 습식 / 건식 / 준비작동식 / 일제살수식 배관

    습식, 건식, 사전 작동식, 일제 살수식 스프링클러 방식.

    Incipient Stage · 초기 단계

    연기 발생 전의 화재 초기 단계. 조기 감지 대상이다.

    Clean Desk Policy · 깨끗한 책상 정책

    자리를 비울 때 문서와 매체를 보관하는 저비용 통제.

    Physical Penetration Test · 물리 침투 테스트

    테일게이팅과 위장 등을 실제로 시험하는 평가. 서면 승인이 필수다.

    연습문제 5개

    문항을 선택하면 본문의 지문과 해설로 이동합니다.

    1. 울타리, 보안 카메라, 출입문 자물쇠는 각각 주로 어떤 기능을 하는가?
    2. 보안 강화를 위해 시설 전체의 전자 잠금이 fail-secure 로 설정되었다. 정전 훈련에서 일부 구역에서 직원이 나올 수 없음이 발견되었다. 잠금을 어떻게 구성해야 하는가?
    3. 승인된 물리 침투 테스트에서 커피 두 잔을 든 테스터가 출입구에서 대기했고 직원이 문을 잡아주어 제한 구역 접근이 허용되었다. 이를 가장 효과적으로 해소하는 조합은?
    4. 침투 테스트에서 테스터가 방문자 회의실의 활성 상태 사내 네트워크 포트에 소형 기기를 연결해 원격 접근을 확보했다. 이를 해소하는 통제는?
    5. 물리 보안 점검 결과다. ㉠ 경계 센서 경보가 잦아 경비가 확인 없이 종결한다. ㉡ 모든 전자 잠금이 fail-secure다. ㉢ 직원들이 낯선 사람에게도 문을 잡아 준다. ㉣ 퇴사자 출입증 34건이 활성 상태다. 가장 적절한 대책 묶음은?
