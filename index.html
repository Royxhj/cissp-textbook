    CISSP 이해형 교재

    ISC2 CISSP Exam Outline (2024-04-15 발효) 기준 · 제작 완료 62 / 62 단원

    개념이 왜 필요한지, 무슨 뜻인지, 어디에 쓰이는지, 다른 단원과 어떻게 이어지는지를 설명하는 교재입니다. 위 검색창은 만들어진 모든 단원을 한꺼번에 찾습니다.

    공부 순서

    1. 본문과 비교표에서 각 개념이 해결하는 문제를 확인합니다. 익숙하지 않은 용어는 연결된 절에서 앞 개념을 찾아봅니다.
    2. 아래 목차에서 단원 옆 문제를 누르면 연습문제 목록이 열립니다. 문항을 선택하고 지문을 읽은 뒤 해설을 펼쳐 판단 근거를 확인합니다.
    3. 핵심 요약을 읽기 전에 ‘핵심 개념을 내 말로 설명하기’를 풀어 봅니다. 근거까지 말하기 어려웠던 개념은 해당 절로 돌아갑니다.

    이 교재는 2024년 발효 개요를 기준으로 합니다. ISC2는 2027년 4월 15일부터 새 개요를 적용합니다. ISC2 공식 시험 개요

    읽는 법본문은 출처에 따라 다섯 가지로 구분됩니다.

    • 표시 없는 본문 — 원본 정리 파일(content/)의 내용을 풀어 쓴 것. 각 절 끝에 원문 위치가 있습니다.
    • 보충 — 원본에 없어 이해를 돕기 위해 더한 설명
    • 가상 예시 — 지어낸 상황. 실제 회사나 제품의 사실이 아닙니다.
    • 연결 — 다른 단원의 개념과 어떻게 이어지는지. 원본의 해당 단원 내용에 근거합니다.
    • 확인 필요 — 원본 서술이 단순하거나 자료마다 달라 그대로 확정하지 않은 부분

    ‘자작 상황 문제’는 교재용으로 새로 만들었고 ‘원본 연습문제’는 저장소의 문제에서 골랐습니다. 실제 시험 문항은 싣지 않았습니다.
